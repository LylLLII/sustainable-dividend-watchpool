# 可持续高股息价值投资观察池

基于《可持续高股息估值底价值投资策略》建立的**高股息观察池**与**实时预期股息率看板**。

## 核心逻辑

> **可持续预期股息率 = 预期每股分红 ÷ 当前股价 × 100%**

股价越低，在公司分红能力不变的情况下，可持续预期股息率越高 → 长期资金吸引力增强 → 形成动态估值下限。

### 估值区间（参考策略文档）

| 可持续预期股息率 | 状态 |
|---:|---|
| < 5% | 正常 / 偏贵 |
| 5% ~ 6% | 开始低估 |
| 6% ~ 7% | 明显低估 |
| 7% ~ 8% | 深度低估 |
| ≥ 8% | 极端低估，重点研究 |

### 参考加仓档位（策略文档第七节）

| 预期股息率 | 动作 |
|---:|---|
| 5% | 小仓位建仓 |
| 5.5% ~ 6% | 加一点 |
| 7% | 明显增加 |
| 8%+ | 基本面仍稳定 → 重点配置 |

⚠️ 加仓必须同时满足：**价格更低 + 企业价值没有明显恶化 + 可持续预期股息率更高**，且遵守仓位上限（如单票不超过组合 20%）。

## 功能

- 📊 **实时行情**：腾讯行情接口，盘中约 3 秒刷新（自动每 30 秒刷新一次）
- 💰 **可持续预期股息率**：预期每股分红 ÷ 实时现价
- 🏷️ **估值区间自动标注**：正常 / 开始低估 / 明显低估 / 深度低估 / 极端低估
- 📈 **历史股息率区间**：基于 52 周高低价计算
- 🎯 **参考加仓价**：一键查看 5%/6%/7%/8% 股息率对应的买入价
- ➕ **添加 / 编辑 / 删除**股票（本地持久化到浏览器 localStorage，可导出 JSON）
- 🔍 搜索、筛选、排序

## 使用方法

### 在线看板

直接打开 `index.html`，或部署到 GitHub Pages / 任意静态服务器即可使用。

### 添加股票

1. 点击右上角「添加股票」
2. 输入代码：`sh601088`（沪）、`sz000895`（深）、`hk00883`（港股）、`usAAPL`（美股）
3. 名称和现价自动识别
4. 填写**预期每股分红**（元/股，可参考最近已宣告分红年化估算）
5. 保存

### 维护预期分红

「预期每股分红」是股息率计算的关键输入，建议：

- 每年年报 / 中报分红方案公告后更新
- 关注分红政策变化（如公司公告下调分红率，应同步下调预期值）
- 结合盈利与现金流判断分红可持续性（策略文档第二、五节）

### 数据备份

页面修改保存在浏览器 localStorage，点击「导出数据」可下载 JSON 备份；也可直接编辑 `data/watchpool.json`（默认初始数据）。
