# 可持续高股息价值投资 · 观察池 + 策略回测一体化

基于《可持续高股息估值底价值投资策略》建立的**高股息观察池**、**实时预期股息率看板**与**策略回测验证引擎**。

> **一站式工作流**：看板（实时监控）→ 回测（历史验证）共享同一份 `data/watchpool.json`，
> 改了观察池即可一键验证策略历史表现。

## 核心逻辑

> **可持续预期股息率 = 预期每股分红 ÷ 当前股价 × 100%**

股价越低，在公司分红能力不变的情况下，可持续预期股息率越高 → 长期资金吸引力增强 → 形成动态估值下限。

### 估值区间（参考策略文档）

| 可持续预期股息率 | 状态 |
|---:|---|
| < 5% | 正常 / 偏贵 |
| 5% ~ 6% | 开始低估 |
| 6% ~ 7% | 明显低估 |
| 7% ~ 8% | 深度低估 |
| ≥ 8% | 极端低估，重点研究 |

### 参考加仓档位（策略文档第七节）

| 预期股息率 | 动作 |
|---:|---|
| 5% | 小仓位建仓 |
| 5.5% ~ 6% | 加一点 |
| 7% | 明显增加 |
| 8%+ | 基本面仍稳定 → 重点配置 |

⚠️ 加仓必须同时满足：**价格更低 + 企业价值没有明显恶化 + 可持续预期股息率更高**，且遵守仓位上限（如单票不超过组合 20%）。

## 功能

### 🟡 自动数据（实时获取）
- 实时现价 / 涨跌幅（盘中约 3 秒刷新，页面每 30 秒轮询）
- **TTM 股息率**：最近 12 个月分红 ÷ 现价，无需手动维护
- **PE(TTM) / PB**：估值水平
- **52 周高低价** → 52 周股息率区间
- **自动预期每股分红**（A股全覆盖）：从东方财富分红接口拉取最近分红方案，按"最近 12 个月已实施分红"年化自动计算；点「✨ 自动更新分红」批量计算，每行「采用」一键覆盖预期值
- 行情加载含**缓存 + 自动重试 + 主备双源**（腾讯 → 东方财富），刷新后不再空白

### 🔵 预期数据（自行维护，策略核心）
- **可持续预期股息率** = 预期每股分红 ÷ 实时现价
- **估值区间自动标注**：正常 / 开始低估 / 明显低估 / 深度低估 / 极端低估
- **参考加仓价**：5%建仓 / 6%加 / 7%重 / 8%重点 对应的买入价

### 🟢 参考指标（借鉴成熟产品思路）
- **派息率参考**（= TTM股息率 × PE，参考 DividendRanks）：衡量分红可持续性，>100% 提示分红可能难以为继
- **股息率百分位**（52 周区间内当前预期股息率的位置，类似乐咕乐股的股息率百分位）：越接近 100% 说明股息率处于历史高位区（越便宜）
- **分红历史**（近三年实际分红记录）与**下次除息日**（45 天内除息高亮提醒）
- **超额收益率**（预期股息率 − 10年国债收益率，对应 MR Dang C4 股息率五步测算第④步"对比国债"）
- **C32 股息率安全边际分级**：资源类股票标注"7%红线"（MR Dang 2026-07-01 半年复盘升级），稳健类以 5% 为参考线

> 📖 **MR Dang 股息率完整方法论**（TTM vs 预期股息率、C4五步测算、C32安全边际、A14股本位等）：见 [docs/MR-Dang-股息率方法论.md](docs/MR-Dang-股息率方法论.md)

### 其他
- **☁️ 云端同步（多电脑共用）**：页面内置 GitHub 直连——以仓库 `data/watchpool.json` 为唯一权威；任一台电脑改完点「⬆ 推送云端」写回仓库，其他电脑点「⬇ 拉取云端」即同步（需在页面填写 GitHub Token：Settings → Developer settings → Personal access tokens，勾选 repo 权限；Token 仅存本机浏览器）
- **🚪 买卖区状态徽章**：每只股票按预期股息率自动标注「卖出区(≤4%)/持有区(4~5%)/买入区(5~6%)/低估区(6~8%)/极端低估(≥8%)」——低股息率的股票**保留跟踪**（对应卖出决策），不删除
- **🔍 自定义阈值筛选**：可输入任意股息率阈值（如 4%），按 ≥ 或 ≤ 筛选，灵活跟踪任意买卖线
- **📈 点击股票名称 → 弹出实时K线图**（腾讯K线接口 + ECharts）：日K/周K/月K切换、MA5/10/20均线、成交量、红涨绿跌，可跳转腾讯行情页
- 添加 / 编辑 / 删除股票（本地持久化到 localStorage，可导出 JSON）
- 搜索、区间筛选、排序（按预期股息率）

## 使用方法

### 在线看板

直接打开 `index.html`，或部署到 GitHub Pages / 任意静态服务器即可使用。

### 添加股票

1. 点击右上角「添加股票」
2. 输入代码：`sh601088`（沪）、`sz000895`（深）——当前观察池专注 A 股
3. 名称和现价自动识别
4. 填写**预期每股分红**（元/股，可参考最近已宣告分红年化估算）
5. 保存

### 维护预期分红

「预期每股分红」是股息率计算的关键输入，**已支持自动获取**：

1. 点击「✨ 自动更新分红」（A股自动从东方财富分红接口计算最近12个月已实施分红合计）
2. 对比表格中「自动 X.XX 元」与当前值，差异明显时点击「采用」一键更新
3. 仍建议每年年报/中报分红方案公告后复核，关注分红政策变化（如公司公告下调分红率，应同步下调预期值）
4. 结合盈利与现金流判断分红可持续性（策略文档第二、五节）

### 数据备份

页面修改保存在浏览器 localStorage，点击「导出数据」可下载 JSON 备份；也可直接编辑 `data/watchpool.json`（默认初始数据，含近三年分红历史 divHist）。

### 看板与回测的关系

```
index.html（实时监控）──→ data/watchpool.json ←── backtest/（历史回测）
                              ↑ 唯一权威数据源
                    改了观察池 → 回测自动用新值
```

- **看板**：实时显示 52 只高股息股的预期股息率、估值区间、加仓参考价
- **回测**：对同一批 52 只股做历史回测，验证「股息率≥5%买入、≤3%卖出」策略的真实收益
- **共享**：`data/watchpool.json` 是唯一权威数据源；回测前运行 `python backtest/sync_watchpool.py` 同步最新股票池

## 策略回测（backtest/）

对同一批 52 只高股息股做可复现回测：**买入 = 股息率高(≥5%) 且 历史百分位便宜；卖出 = 股息率低(≤3%) 且 百分位贵；中间持有。**
按月再平衡，分红自动复投，含完整交易成本（佣金/印花税/滑点/整手/延迟）。

### 快速使用

```bash
cd backtest
python sync_watchpool.py          # 同步上层 watchpool.json
node validate_engine.mjs           # 运行校验（13/13 全绿）
```

浏览器打开 `backtest/backtest_tool.html` 可交互调参回测。
