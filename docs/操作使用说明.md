# 高股息投资决策系统 · 操作使用说明

> 版本：V1.3（冻结版）｜ 最后更新：2026-08-07
>
> 本说明按**使用场景**组织：先 2 分钟上手，再讲日常看盘、季度维护、买卖决策、多设备同步。功能多，但真正需要你动手的只有两件事——**季度维护**和**按决策列执行**，其余都是辅助。

---

## 一、快速开始（2 分钟）

1. 打开在线版：`https://lylllii.github.io/sustainable-dividend-watchpool/`
2. **第一次务必强刷**：`Ctrl+Shift+R`（Mac：`Cmd+Shift+R`），否则看不到新功能
3. 看表格最后一列**「决策建议」**——这是系统的核心输出，每一行直接告诉你：这只股票现在**该买、该等、还是该退**

如果表格太宽不好看：
- 点工具栏 **「☰ 列」**，把不关心的列勾掉（只留 `股票 / 现价 / 预期股息率 / 估值区间 / 决策建议 / 备注` 就很清爽）
- 表格左右拖动时**股票列固定不动**（冻结），不会看串行

## 三、日常看盘（每天 / 每周，5 分钟）

### 1. 看「决策建议」列的状态徽章

| 徽章 | 含义 | 建议动作 |
|---|---|---|
| 🔥 极端低估 | 股息率 ≥8%（资源类 ≥10%）| 基本面+分红确认后才能重仓 |
| 🟠 深度低估 | ≥7%（资源 ≥9%）| 可加仓至 12% |
| 🟢 加仓区 | ≥6%（资源 ≥8%）| 可加仓至 8% |
| 🟢 建仓区 | ≥5%（资源 ≥7%）| 可建底仓 3% |
| 🤔 持有区 | 建仓线与减仓线之间 | 持有不动，别折腾 |
| 🟡 减仓评估区 | ≤4.2%（资源 ≤6.2%）| 估值修复，评估减仓 |
| 🔴 退出评估区 | ≤3.8%（资源 ≤5.8%）| 停止新增，评估退出 |

> ⚠️ 徽章只是**触发条件**，不是买入理由。**最终能不能执行，看两个闸门**（见第五节）。

### 2. 快速分层查看

- 筛选下拉选「低估及以上」「卖出区」等，只看某一层
- 排序按「预期股息率↓」，便宜的排最上面

### 3. 看走势

- **点股票名称** → 弹出 K 线图（日/周/月切换，红涨绿跌），右上角可跳转腾讯行情
- 「除息日」列显示最近除息日期，临近 45 天内会标红提醒

## 四、季度维护（每季度 30 分钟）——**最重要的动作**

> 系统的准确性完全取决于你维护的质量。每季度做一次，动作固定：

### 第 1 步：更新自动分红

点右上角 **「✨ 自动更新分红」** → 系统从东财拉取最近 12 个月实际分红（**Auto 后视值**），显示在每行"预期股息率"列下方。

### 第 2 步：对比 Auto vs 前瞻

- **Auto 后视 X.XX** = 过去 12 个月实际到账的分红（后视镜，只看历史）
- **前瞻 X.XX 元** = 你人工维护的预期分红（Forward DPS，估值锚，前挡风玻璃）

**如果两者差异明显**，说明分红可能有变化（提高/削减/一次性），需要你判断。

### 第 3 步：确认 Forward DPS（估值锚）

点决策列里 **expDps 按钮**：
- `🟡 自动·未确认` → 点一下 → 选择**确认依据**（年报 / 中报 / 分红公告 / 自己估算）→ 变成 `🟢 已确认`
- 确认后自动写入：确认日期 + 90 天后的复核日期
- **超过复核日期自动变成 🔴 过期**，深度低估档的加仓建议会降级为"待复核"——不需要你记着去改

> 也可以点自动值旁的「采用」按钮，把 Auto 值一键设为前瞻值，再走确认流程。

### 第 4 步：基本面结构化检查

点决策列里 **基本面按钮** → 弹出 6 项勾选：

```
□ 盈利：净利润无明显恶化
□ 现金流：经营现金流无明显恶化
□ 分红：分红政策无明显恶化
□ 负债：负债风险无明显恶化
□ 主业：核心业务无明显恶化
□ 重大事件：无重大负面事件（未勾选 = 一票否决 🔴）
```

- 自动评分：5 项通过→🟢 正常 / 3~4 项→🟡 观察 / ≤2 项→🔴 逻辑破坏
- **重大事件未勾选 → 直接 🔴**（一票否决，不能被其他项掩盖）
- 填一句**理由**（如"2026Q2净利润同比降18%，等分红政策确认"）
- 保存后自动写入复核日期：**资源/周期股 60 天，其他 90 天**；超过后自动变「⏰ 待复核」
- 🔴 不会自动恢复，但问题解决后**重新做一次检查**即可解除

### 第 5 步：检查"待复核"标记

页面里出现 `⏰` 的股票 = 复核过期，按上面第 3、4 步重新确认即可。

## 五、买卖决策怎么读（决策矩阵）

决策列每行由几部分组成：

```
🟠 深度低估                    ← 状态徽章
建议仓位 12%                   ← 目标仓位（受双闸门影响）
下一档 4.30元（10%）            ← 下一档买入价 = 前瞻分红 ÷ 下一档股息率
依据：预期股息率 9.11% ≥ 9%档（资源类）  ← 为什么是这个结论
卖出：≤6.2%减 / ≤5.8%退出        ← 卖出线
基本面 🟢 正常 ｜ expDps 🟢 已确认 ← 两个闸门的状态（可点击修改）
⏰/⚠️ 提示                       ← 闸门拦截原因（如果有）
```

**核心逻辑：状态徽章是"估值信号"，两个闸门决定"能不能执行"：**

| 估值信号 | 基本面 | Forward DPS | 最终结论 |
|---|---|---|---|
| 深度低估 9% | 🟢 | 🟢 已确认 | ✅ 建议仓位 12%，下一档 4.30 元 |
| 深度低估 9% | 🟡 观察 | 🟢 | ⚠️ 暂停新增（持有不动）|
| 深度低估 9% | 🔴 破坏 | 🟢 | 🔴 禁止买入（0%）|
| 深度低估 9% | 🟢 | 🟡 未确认 | ⚠️ 待复核（不给仓位建议）|
| 深度低估 9% | 🟢 | 🔴 过期 | ⚠️ 先重新核算 Forward DPS |

**一句话**：股息率高 ≠ 可以买；**高股息 + 基本面 🟢 + 分红确认**，三者齐了才执行档位。

## 六、股票管理（增 / 删 / 改）

- **添加**：右上角「＋ 添加股票」→ 填代码（`sh601088` / `sz000895`）→ 填预期每股分红 → 填行业/主营 → 勾是否资源类 → 保存
- **编辑**：行尾「编辑」→ 改任何字段（含行业、主营、资源类标记）
- **删除**：行尾「删除」
- **导出**：右上角「⬇ 导出数据」→ 下载合并后的完整 JSON（含你的所有修改）

> ⚠️ 网页上的增删改**只存在你本机浏览器**（差异同步机制）。要让全平台生效，见第七节。

## 七、多设备同步（家里 / 单位电脑）

系统以 **GitHub 仓库为唯一权威**，两台电脑用同一个在线版网址即可互通：

1. **每台电脑各配一次 Token**（GitHub → Settings → Developer settings → Fine-grained tokens → 生成，权限只需 Contents 读写）→ 粘贴到「☁️ 云端同步」栏 → 保存
2. **日常**：家里改完 → 点「⬆ 推送云端」；到单位打开 → 点「⬇ 拉取云端」→ 两边一致

两个概念要分清：
- **拉取云端** = 把仓库最新数据拿下来，但**不覆盖**你本地的增删改（自动合并）
- **推送云端** = 把你本地的增删改**写回仓库**，成为全平台正式数据

> 不想配 Token 也行：网页改完点「📋 复制变更摘要」→ 粘贴发给你的 AI 助手，它会帮你更新仓库。

## 八、自定义参数

### ⚙ 决策参数（工具栏）

| 参数 | 默认 | 说明 |
|---|---|---|
| 单票最大仓位 | 20% | 极端低估档的仓位上限 |
| 减仓线偏移 | 0.8pp | 减仓线 = 建仓线 − 偏移（如 5−0.8=4.2%）|
| 清仓线偏移 | 1.2pp | 退出线 = 建仓线 − 偏移（如 5−1.2=3.8%）|

> 滞回参数只是**执行规则**，防止来回交易，**不代表估值合理区间**。改动存本机浏览器。

### ☰ 列显隐

15 个数据列可随意开关，股票列和操作列固定。选择存本机，可「恢复默认」。

## 九、概念速查表

| 概念 | 是什么 | 怎么用 |
|---|---|---|
| Auto DPS | 东财自动计算：最近12个月实际分红年化（**后视**）| 参考值，不能直接当估值锚 |
| Forward DPS | 你人工确认的**前瞻**可持续分红 | **真正的估值锚**，股息率用它算 |
| 预期股息率 | Forward DPS ÷ 现价 × 100% | 系统所有判断的输入 |
| 5/6/7/8 档 | 执行档位（资源类 7/8/9/10）| 触发条件，**不是估值真理** |
| 滞回/持有区 | 买入线和卖出线之间的缓冲带 | 防止买完就卖、卖完就买 |
| 双闸门 | 基本面 + Forward DPS 确认 | 拦截"高股息但基本面坏/分红不可信" |
| 差异同步 | 仓库为基准 + 本地记录增删改 | 仓库更新自动出现，你的修改保留 |

## 十、常见问题

**Q：行情没数据 / 显示"行情获取失败"？**
自动重试 + 显示上次缓存数据。网络恢复后几秒自动补上；若持续失败，看右上角行情时间旁的提示文字。

**Q：我加的新股票看不到？**
先强刷（Ctrl+Shift+R）。如果仍没有，可能是本机旧缓存数据覆盖——点「🗑 放弃本地修改」恢复仓库基准再看。

**Q：☰ 列里找不到某列了？**
点「恢复默认」即可全部找回。

**Q：云端拉取报 404？**
确认 Token 已保存（私有仓库拉取/推送都需要 Token），且 GitHub 里 Token 权限勾了 Contents 读写。

**Q：本地改的和云端哪个算数？**
以**云端仓库为准**（正式版）；本机差异是"草稿"。推送云端后草稿转正。

## 十一、当前定位（重要）

- 本系统是**规则化决策工具**，不是"自动驾驶"。它告诉你**按什么规则、为什么**，最终决定权在你。
- 每季度维护的质量（Forward DPS 确认、基本面检查）**决定系统可靠性**——它错则系统错。
- 系统正处于**观察期**：用它记录真实的决策数据，1~2 个季度后回看，验证"高股息+可持续分红+基本面未破坏"是否真的形成收益优势。

> 本页面与文档不构成投资建议。
