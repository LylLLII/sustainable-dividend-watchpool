# 高股息策略回测工具（dividend-backtest）

对「sustainable-dividend-watchpool」52 只高股息股的价值策略做可复现回测：
**买入 = 股息率高(≥买入触发线) 且 历史百分位便宜；卖出 = 股息率低(≤卖出触发线) 且 百分位贵；中间持有。**
按月/季再平衡，分红自动复投，单票上限 20%、总仓不杠杆。

## ⚠️ 结论先行（2026-08-10 完整 52 只池回测后，更新）

**评级：研究工具 Ready with caveats；投资收益证明：策略跑赢全部基准（乐观口径）。**
策略低波动、回撤较小，且长期收益高于中证红利与标普500基准。

修复前视偏差并计入交易成本后，策略在完整 52 只池上跑赢全部基准：

\* 夏普为标准日度超额收益口径：mean(日收益 − 1.7%/252) / std(日超额收益) × √252。

**投资层面的判断：**
- 策略**在 52 只完整池上跑赢全部基准**：10.26% > 中证红利 8.62% > 标普500ETF 9.76% > 沪深300 4.87%。
- 主要优势是**较低波动和较小回撤**（13.8% / -29.2% vs 基准 21-24% / -44~-60%），风险调整后收益显著更优。
- 2022–2025 三年窗口 CAGR 达 19.08%，高度依赖最近分红潮，**仍不能完全外推为长期稳定收益**。
- 工具默认软倾斜模式 7.56%，低于纯档位 10.26%（真实股息率下"便宜区"触发较少）。
- 与此前 13 只测试池相比（CAGR 6.80%），扩展到 52 只后收益显著提升，说明更大的候选池提供了更多轮换机会。

**与旧版 13 只测试池对比（评审核心发现）：**
1. **前视偏差（已修）**：旧版把当前 watchpool 的 `expDps` 回填进 2015–2024 缺失年份。
   例：中国神华 2016 年真实分红 0.32 元/股，旧版却用今天的 2.01 元回填 → 历史股息率信号
   被放大数倍，同时吃到大量「幽灵分红复投」。**这是旧版 15.83% 的主要水分来源。**
2. **策略定义变化（已标注）**：本回测的股息率是 **realized-TTM**（最近12个月真实已实现分红/价），
   严格说是一个**派生策略**，已不是原始 watchpool 的「预期股息率 expDps/价」定义 ——
   后者有前瞻偏差无法直接回测。结论只适用于 realized-TTM 口径。
3. **交易成本（已加，策略与基准对称）**：佣金万2.5(最低5元)+印花税卖出0.1%→0.05%(2023-08-28)
   +滑点0.1%单边+买入整手100股+调仓/分红复投延迟各1日；**基准同样计入建仓与分红复投成本**。
4. **幸存者偏差（已标注，未消除）**：固定 watchpool.json 时点的完整股票池，未含历史剔除/退市股，
   收益系统性偏乐观。本结果应理解为**「当前股票池」回溯测试**。

**策略的真实特征**（诚实口径下）：高股息触发线 5%（资源 7%）在 2015–2020 年较少触发
（当时真实股息率普遍偏低），组合长期持币、波动很低但收益平庸；2023–2024 煤炭/金融
分红潮才大幅建仓（年度收益 +18.98%/+37.16%）。滚动窗口：2022 年起跑 CAGR 14.49%（受益分红潮）。

## 数据与口径

- **股票/基准 K 线**：腾讯行情 `web.ifzq.gtimg.cn`（raw 日线，2000 根/次向后分页）。
- **策略股分红**：东财 datacenter `RPT_SHAREBONUS_DET` 真实历史除息事件（含税
  `PRETAX_BONUS_RMB/10`，与 watchpool divHist 口径一致，已交叉验证）。**无任何前瞻回填**：
  当年未宣布的分红，当年就没有事件（=「当时可知」口径）。
- **基准**：3 个统一为「价格 + 估算分红复投」的**近似全收益**（真实全收益指数 H00300/H00922
  经探测腾讯/东财均不可得）：中证红利 4.5%/年、沪深300 2.5%/年、标普500ETF 1.8%/年，
  每年 7 月首个交易日为除息锚点。**基准与策略使用同一套交易成本**（建仓佣金+滑点、分红复投费用），
  口径对称。非官方全收益指数，差值不可解读为精确 alpha。
  > 注：旧版把 sh000985 标为「沪深300全收益」，实测其数据是**中证全指（价格指数）**，
  > 本轮已用真实沪深300（sh000300）替换。
- **基准断档**：>30 天的缺口线性插值补齐（人工路径，已在 meta 标注）。

## 使用

```bash
# 1) 拉真实分红 + K 线（可跳过 2/3 的 fetch，hist/ 与 data/ 已带数据快照）
python fetch_real_divs.py      # -> data/real_divs.json（东财真实分红）
python fetch_tencent.py        # -> hist/<code>.json（完整股票池 K 线）
python fetch_benchmark.py      # -> hist/bench_*.json（3 基准）
# 2) 构建数据
python apply_watchpool_divs.py # 用真实分红覆写 divs（去前视）
python apply_benchmark_divs.py # 给价格基准注入估算分红（近似全收益）
python generate_bundle.py      # -> backtest_bundle.json（工具页数据）
# 3) 回测
python dividend_backtest.py    # 双模式 -> hist/summary_metrics.json + equity CSV
# 4) 校验双引擎 0 偏差
node validate_engine.mjs       # JS/Python 对照 + 口径/滚动窗口检查
# 5) 交互工具
python -m http.server 8000     # 打开 http://localhost:8000/backtest_tool.html
```

依赖：核心管道纯 Python 标准库；`make_chart.py`（净值图）需 matplotlib。所有脚本读写
均显式 `encoding="utf-8"`，Windows 下可直接运行（见 requirements.txt）。

## 已知局限（未修复项）

- 幸存者偏差：无法重建历史成分股，结果明确限定为「当前股票池回溯测试」。
- 基准分红为估算（近似全收益），非官方全收益指数。
- 分红为含税口径，未扣红利税；实际到手略低。
- 无涨跌停/停牌限制；滑点为固定比例近似。
- 保守闸门（分红同比下滑>1% 不新开仓）在真实分红口径下触发频率低（约 4–5% 月份）。
