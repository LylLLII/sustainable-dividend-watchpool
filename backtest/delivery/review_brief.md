# 回测工具评审报告 · Brief

对 watchpool 股息率策略交互式回测工具进行了六维度全面评审。

### 方法
- 4 路并行 Agent 分维度审查（引擎逻辑 / 数据管道 / UI 健壮性 / 百分位发现核验）
- 主线独立运行 validate_engine.mjs 复算
- 三组关键参数对照（纯档位 / 30/70 / 100/100）
- 个股信号手工校验（3 只抽样）

### 问题清单

- **阻断 P1**: conservative 模式（gate_ok 闸门）缺失
- **重要 P2**: targetWeightPure 档位硬编码 vs 参数化
- **重要 I-1**: sellYield > buyYield 无输入校验

### 结论：需修复后交付
