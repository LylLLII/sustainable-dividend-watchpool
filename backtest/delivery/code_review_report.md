## 三、仍存在的问题（按严重度）

### 【重要 · 方法学】P1 — 基准口径不一致，策略 vs 基准不公平对比

- **现象**：3 个基准中，`中证红利(价格) sh000922` 与 `标普500 ETF(价格) sh513500` 是**价格指数/价格 ETF**，`divs=0`，benchmark 不做分红复投 → 基准收益**未计入分红**。而策略是「含分红复投」的。`沪深300全收益 sh000985` 是含分红指数（divs=0 正确，分红已计入价格）。
- **影响（直接扭曲结论）**：
  - 策略含分红 CAGR **16.03%** vs 标普价格口径 **7.76%**——但标普真实「价格+分红+汇率」长期年化应 ~12%+，此处被压到 7.76%。
  - 中证红利价格口径 **3.78%** 同样严重低估（其全收益同期应 ~8–9%）。
  - 「策略大幅跑赢标普/中证红利」的结论，有一部分来自**基准少算了分红**，并非策略纯 alpha。
- **证据**：`validate_engine.mjs` 输出；`hist/*bench*.json` 的 `divs=0`；`generate_bundle.py` L49–54 仅标注口径，未补分红。
- **修复建议（任选其一）**：
  1. 改用「全收益」对标基准（如中证红利全收益、标普500 全收益 ETF）；
  2. 对 ETF 用真实分红流做 DRIP（标普500 ETF 年化分红约 1.5–2%）；
  3. **最低限度**：在图表与报告显著标注「价格基准未含分红，与含分红策略不可直接比较」。

### 【重要 · 工程】P2 — `apply_watchpool_divs.py` 脆弱的路径硬编码

- **现象**：L10 硬编码
  ```python
  WP = r"C:\Users\57328\WorkBuddy\2026-08-06-21-53-40\sustainable-dividend-watchpool\data\watchpool.json"
  ```
  这是一个**带时间戳的临时目录**，且**跨项目**引用。
- **影响**：该目录一旦被清理/迁移，权威分红源即失效；脚本既不报错也不提示，会静默用旧数据或崩溃，回测数据管道断裂且无预警。
- **修复建议**：改为相对路径或环境变量（如 `os.environ.get("WATCHPOOL_JSON")`），或将 `watchpool.json` 复制进本项目 `data/` 目录并提交版本控制。

---

### 【重要 · 数据严谨】P3 — 未上市公司被合成「上市前分红」

- **现象**：`apply_watchpool_divs.py` L47–49 对 13 股统一从 2015 起生成年度合成分红。`sh600941 中国移动` A 股 **2022 年才上市**（kline 仅 1112 条，其余股 ~2800 条），却仍生成 2015–2021 的 `expDps` 分红。
- **影响**：当前因 `dates` 轴来自 kline，这些分红实际未进入 panel（属「休眠污染」）；但一旦调早 `start` 或接入更早数据，会引入**虚假 ttm 股息率**。
- **修复建议**：合成分红起点取 `max(2015, 上市首年)`；或仅对「有价格且 divHist 缺失」的年份补。

---

### 【中等 · 数据冗余】P4 — 孤儿基准文件 `hist/bench_sh000300.json`

- **现象**：`hist/` 存在沪深300 价格指数（2818 条，divs=0），但 `BENCH_ALLOW` 不含 `000300`，`generate_bundle.py` 直接忽略它。
- **影响**：制造「到底用了哪个沪深300」的混淆。
- **修复建议**：删除该文件，或纳入 `BENCH_ALLOW` 并明确口径。

---

### 【中等 · 测试脆弱】P5 — `validate_engine.mjs` 用硬编码历史数值做断言

- **现象**：L84–93 断言 `16.03 / 16.29 / 12.21` 等固化 magic number。
- **影响**：数据任何刷新（fetch 重跑、apply 重跑）都会让断言 FAIL，变成「脆断」而非「回归保护」。
- **修复建议**：改为「JS 引擎 vs Python 引擎」互相 diff（容忍 0.x% 浮点误差），或对**相对关系**断言（如 `tilt.CAGR > hardgate.CAGR`）。

---

### 【轻微 · 规范】P6 — `fetch_tencent.py` 关闭 SSL 校验 + 强制清除代理

- **现象**：L4–7 清除所有代理环境变量、`ssl.CERT_NONE` 关闭证书校验。
- **影响**：(1) 在需要代理的网络会强制直连失败；(2) 关闭证书校验有 MITM 隐患（虽公开行情风险可控）。
- **建议**：注释说明用途；允许通过环境变量恢复代理/校验。

### 【轻微 · 可复现】P7 — 无依赖清单与运行管道文档

- `make_chart.py` 需 `matplotlib` + 中文字体；无 `requirements.txt`；无任何文档串起 `fetch → apply → backtest → chart → bundle → validate` 顺序。新人无法复现。

### 【轻微 · 口径】P8 — 夏普/波动率口径

- 夏普用 **CAGR（几何）** 而非年化算术收益，`rf=0.017` 硬编码；波动用**总体标准差**（`pstdev`/除 n）。双引擎一致，但与学术口径略有出入，建议在报告注明定义。

### 【轻微 · 结论稳健性】P9 — conservative 与 optimistic 高度重合

- **证据（本轮统计）**：保守闸门（`ttm_d >= ttm_{d-365}×0.99`）在全样本仅 **4.48%** 的再平衡日触发限制；二者 **MDD 完全相同（−27.84%）**、CAGR 差仅 0.26pp。
- **含义**：「保守/乐观双区间」区分度极低，结论说服力主要靠单一样本期（2015–2026 牛市）。建议增加多 `startYear` 敏感性测试。

## 四、架构评价

- **双引擎分工合理**：Python 离线批量回测 + JS 浏览器内交互，职责清晰；一致性靠 `validate_engine.mjs` 保证（但断言脆弱，见 P5）。
